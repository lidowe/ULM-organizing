# Upper Level Music — Edward Lidow static website

This is a multi-page static website: Home, Credits, About, Approach, Studio, Services, and Contact.

## Files
- `index.html`
- `credits.html`
- `about.html`
- `approach.html`
- `studio.html`
- `services.html`
- `contact.html`
- `assets/css/styles.css`
- `assets/js/site.js`

## Contact form
The contact form uses a `mailto:` action generated by JavaScript and sends to `edwardlidow@upperlevelmusic.com`. For production use, connect the form to a real backend, Netlify Forms, Formspree, or the hosting provider’s form handler if you want guaranteed submission logging.

## Notes
Credit roles are phrased broadly because exact role metadata can differ by track, edition, and source. Final public release should be checked against preferred credit databases or label metadata if exact line-by-line credit language matters.
