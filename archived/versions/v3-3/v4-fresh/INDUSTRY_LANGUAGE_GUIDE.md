# Industry Language Guide (ULM V4)

## Use This Wording
- Pre-production
- Tracking session
- Overdub session
- Punch-in
- Vocal comping
- Tuning pass
- Editing pass
- Mix prep
- Mixing revisions
- Mastering coordination / master handoff
- Producer / executive producer
- Recording engineer
- Mix engineer
- Vocal producer / vocal coaching
- Co-engineer support
- Retained technical support

## Avoid This Wording
- Done-for-you
- Learn-with-you
- Finishing
- Release preparation
- Professional quality (without measurable context)
- Studio magic
- Generic transformation language

## Practical Session Flow
1. Pre-production
2. Tracking and overdubs
3. Comping, tuning, editing
4. Mix prep
5. Mixing and revisions
6. Mastering handoff

## Common Client Types
- Independent artists with demos
- Bands needing tracking + mix support
- Vocalists unfamiliar with studio workflow
- Producer-artists wanting co-production support
- Home engineers needing technical second opinion

## Common Pain Points
- Weak arrangement before mix stage
- Vocal capture/comping inconsistency
- Home mixes not translating
- Session organization problems
- Decision fatigue during revisions

## Messaging Rule
Describe services as role + stage + outcome.
Example:
- "Recording and mix engineering for projects that already have arranged material and need release-grade execution."
