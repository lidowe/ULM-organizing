# Upper Level Music site v3

Multi-page static website for Upper Level Music / Edward Lidow.

Open `index.html` first. The site has embedded CSS and JavaScript in every page so it will render locally without an asset folder or external font dependency.

Pages:
- index.html — artist-first homepage
- work.html / credits.html — selected work, artists, rooms
- services.html — services and rate ranges
- studio.html — private room positioning
- process.html / approach.html — artist-centered process
- about.html — Edward Lidow biography
- contact.html — booking/contact form using mailto

Contact form behavior:
The form drafts an email to edwardlidow@upperlevelmusic.com. For production hosting, replace this with a form handler such as Netlify Forms, Formspree, Basin, a custom serverless function, or your web host’s native form processor.
